# 2026-09-24

## Custom order ID feature (new Order tab)
- Added `includes/core/class-lwc-order-number.php` (`LWC_Order_Number`): builds `SBI-DD_20260924_Local_0001` from prefix + date + scope label + running number + suffix. Scope from shipping country → billing country → base country (ID = local, else global). Assigned on `woocommerce_new_order`, stored in `_lwc_order_number`, shown via the `woocommerce_order_number` filter.
- Counter per scope in `lwc_order_number_seq_{scope}`, incremented atomically with `LAST_INSERT_ID()`; optional daily reset appends the date to the option name.
- Admin: new `order` tab (`lwc_order_options`) in `includes/admin/class-lwc-admin-settings.php` with a general section (enable / daily reset / separator) and one section per scope (prefix, date format, scope label, suffix, number length, start number) plus a server-side "Next order ID" preview.
- Wired in `includes/core/class-lwc-core.php`; version bumped 1.0.83 → 1.0.84; PRD.md gained a "Custom order ID" section and data-model entries.
- Verified with `tmp/test-order-number.php` (all 15 fields render; local/global sequences, daily reset, empty-date/suffix/no-padding variant, raised start, no renumbering, disabled fallback) and `tmp/test-order-number-admin.php`. Everything ran inside a rolled-back transaction, so no test orders or options were left behind.
- Feature ships **disabled** — the store owner must tick "Enable custom order ID" on the Order tab.

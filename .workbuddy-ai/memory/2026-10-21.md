# 2026-10-21 — Penanda login untuk promo (guest CTA → My Account)

Permintaan: tambah tombol/penanda login untuk mendapatkan promo, diarahkan ke
halaman My Account, untuk menarik pembeli yang belum login/mendaftar.

## Yang ditambahkan

**`promo/class-lwc-promo-dashboard.php`**
- `get_promo_login_url( $redirect = '' )` — satu-satunya pembentuk URL undangan:
  `my-account?redirect_to=<cart|checkout>`. Default: `is_cart() ? cart : checkout`.
  `add_query_arg()` sudah meng-encode sendiri → jangan pre-encode (double-encode
  merusak redirect).
- `get_requested_promo_redirect()` — membaca `redirect_to` dari `$_GET`/`$_POST`,
  lalu `wp_validate_redirect( $url, '' )`. Host asing / scheme non-http → string
  kosong → jadi open-redirect guard.
- `promo_login_redirect()` (filter `woocommerce_login_redirect`) dan
  `promo_registration_redirect()` (filter `woocommerce_registration_redirect`) —
  keduanya mengembalikan shoppers ke halaman checkout/cart setelah login/daftar.
- `render_promo_redirect_field()` (action `woocommerce_login_form` +
  `woocommerce_register_form`) — menyuntik `<input type="hidden" name="redirect">`.
  **Penting:** template My Account milik WooCommerce (9.9.0) tidak punya field
  `redirect` sama sekali; form-nya post ke URL saat ini (tanpa `action`), jadi
  query string ikut terbawa. Field hidden hanya dirender kalau Pengunjung benar
  datang lewat undangan, sehingga perilaku stock customer lain tidak berubah.
- `render_guest_promo_login_prompt()` — markup ajakan login (kelas
  `lwc-guest-promo-login`), berdiri di tempat kolom kupon native yang disembunyikan.
- `render_coupon_dashboard()` untuk guest → kartu "Coupons & Promo" + tombol
  `Login / Register` (kelas `lwc-promo-dashboard-actions`).

**`promo/promo-dashboard.js`** — `renderGuestInvite()` hanya membuat ajakan
login; skip kalau server sudah merender `.lwc-checkout-account-promo` (cart &
checkout klasik), jadi tidak ada duplikat di Checkout Block.

**`promo/promo-dashboard.css`** — gaya CTA utama + tombol My Account.

Header + `LWC_VERSION` bumped 1.0.99 → 1.1.0.

## Verifikasi

`tmp/test-promo-login-cta.php` (self-deleting, dua mode karena
`render_checkout_coupons()` memakai static guard):

- mode **guest**: 28 checks, 0 gagal.
- mode **customer**: 25 checks, 0 gagal.
- Tidak ada residu kupon uji di DB; harness terhapus sendiri.

Yang diperiksa: URL undangan menunjuk My Account + `redirect_to` ter-encode
sekali; filter login/registrasi memakai tujuan valid; host asing dan
`javascript:` ditolak; field hidden ada/tidak sesuai permintaan; guest melihat
penanda (tanpa kode kupon) dan field kupon native mati; customer tetap melihat
kartu promo, field kupon native hidup, dan tidak pernah melihat ajakan login.

## Catatan

- `wp_validate_redirect( $url, '' )` mengembalikan string kosong untuk host
  asing — dipakai sebagai sinyal "tolak" (fallback `''`, bukan URL default).
- `render_checkout_coupons()` memakai `static $rendered` → **satu render per
  request**, dan statiknya dipakai bersama antar-instance (bukan per-instance).
  Harnes harus dijalankan per-mode dalam proses terpisah.
- Pratinjau visual: `promo-login-cta-preview.html` di root plugin (dibuat dari
  markup + CSS asli plugin).

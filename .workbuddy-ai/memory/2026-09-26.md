# 2026-09-26

## Custom order ID — manual correction (v1.0.87)

Added admin ability to manually correct a mis-assigned order number.

**New files:**
- `includes/admin/class-lwc-order-number-admin.php` (`LWC_Order_Number_Admin`):
  - `register_metabox()` → adds "Order Number" side metabox on `shop_order` and HPOS `woocommerce_page_wc-orders` screens
  - `render_metabox()` → shows WooCommerce internal ID, current custom ID, scope (readonly), and a correction text field (disabled for pre-feature orders)
  - `ajax_correct_order_number()` → AJAX handler (`wp_ajax_lwc_correct_order_number`) with duplicate guard + scope re-derivation
- `includes/admin/lwc-order-number-admin.css` — metabox styling
- `includes/admin/lwc-order-number-admin.js` — save button AJAX handler, updates displayed ID in place on success

**LWC_Order_Number changes:**
- Added `order_id_exists($custom_id, $exclude_order_id = 0)` — duplicate check querying HPOS `wc_orders` + `wc_order_meta` then CPT `postmeta`; used by the AJAX handler to block corrections that would create a duplicate

**LWC_Core changes:**
- Requires the new admin file in constructor
- `init_hooks()`: instantiates `LWC_Order_Number_Admin` and calls `init()` in admin context only

**LWC_Order_Number_Admin::render_metabox() logic:**
- Feature disabled → "currently disabled" message
- Pre-feature order (`! is_eligible_for_number()`) → read-only notice, no field
- Eligible order → shows WooCommerce #, current custom ID, scope, editable text field + Save button

**AJAX guard chain:** permission check → valid order ID → order found → `is_eligible_for_number()` → duplicate check (if new value differs) → write meta + scope → return saved value

**PRD.md updated** with manual correction section; version bumped to 1.0.87.
